One direction, built out properly this time: a real semantic mapping for the dial (not decoration), a second signal colour so "working" and "needs you" can never be confused, and a genuine answer for long conversation — a paper logbook set into the housing, not a mono wall of text.

Everything below is built so a normal person reads it correctly on sight: dials, counters, indicator lights, a flag that pops up, switches you flip. No dashboard vocabulary required.

What the dial actually means

the part the first pass skipped

Amber — Mike is doing something right now
Red flag / redline — Mike has stopped and needs you
Green — finished, and it worked
04 — a trip counter. Ticks once per real completed action. Never a percentage, never a total — because Mike genuinely can't know how many steps are left, and a trip counter doesn't pretend to.

That last point is the actual innovation: an odometer is the one gauge everyone already understands as "how much has happened" rather than "how much is left." It's honest by the shape of the object, not by a caption explaining the honesty policy.
