Visual reset · exploration, not prescription

Three ideas for what Mike could actually look like

No shared design system between these — each is built as if it were the only answer. Judge them as products, not palettes.

01

Instrument

machined · warm · physical

Mike isn't software pretending to be intelligent — he's built like a well-made instrument. A dial, not an orb. Brushed metal and engraved labels instead of glow. The register is Braun, Teenage Engineering, a good amplifier: things you trust because they feel made, not rendered.

Colour

Warm near-black ground (never pure black), brushed-metal mid-tones, one copper-amber signal colour.

Type

Barlow Semi Condensed for engraved panel labels · IBM Plex Mono for readouts · system sans for what Mike actually says.

Layout

A control-panel grid. Bezelled zones, inset grooves, rivets in the corners — real physical tells, not decoration.

02

Studio

glass · depth · macOS-native

Mike as real material, not a flat panel — vibrancy, blur, and layered depth the way macOS itself already speaks. The familiar command-bar pattern, executed with actual craft: true backdrop blur, coloured ambient shadow, generous radii. Confident violet against a warm coral for attention.

Colour

Cool ink ground, glass panels tinted violet, iris-violet as identity, coral reserved for attention.

Type

System sans (Inter/SF) for all UI chrome · Fraunces — warm, characterful serif — for the one moment Mike's own words get to be the hero.

Layout

Floating glass over a visibly blurred desktop. Real depth via shadow layering, not flat cards with borders.

03

Signal

bold · editorial · graphic

The risk-taking one. Mike as a confident graphic mark — a bracket that opens when he's present — rendered big, not restrained to a single pixel of colour. Deep ink ground, one flame accent used generously in full colour blocks. Home reads like a magazine spread, not a utility panel.

Colour

Deep ink-wine ground, one flame accent used boldly — full colour blocks, not a lone highlight.

Type

Big Shoulders Display — tall, poster-weight — for the bracket mark and headlines · Fraunces for Mike's statements · mono for fact.

Layout

Colour-blocked, editorial. The bracket mark is the identity — it opens, holds, and closes as a real graphic event.

▸

Honestly, against each other

Instrument

Strongest. Completely unclaimed territory — nothing in this space looks like this. Cheap to render: SVG arcs and gradients, no blur, no glow. Solves ambient presence elegantly — a resting dial reads as "on" without being loud.

Risk. The gauge is built for a glance, not a paragraph. A long conversation inside a control-panel metaphor hasn't been tested here — it may fight dense prose.

Studio

Strongest. The most immediately expensive-feeling — leverages vibrancy macOS users already trust. Fraunces carries long-form prose better than either other concept's type system.

Risk — found, not guessed. Stacking real backdrop-filter blur across several frames actually hung this page's renderer while building it. Fixed here by keeping true blur to one hero surface and faking the rest with soft gradients — but it means: one glass panel on screen at a time, never several.

Signal

Strongest. The one someone screenshots. Real graphic identity, a mark nobody else owns, genuine confidence.

Risk. The flame block is loud by design — that's the point once, or ten times a day. Whether it's still welcome the five-hundredth time is the real question, and it's the one thing a static mockup can't answer.

My honest pick

Not one of the three whole — a synthesis, because each is strongest at a different depth. Instrument for D0–D2: the dial is the ambient/edge/invocation identity, unclaimed and nearly free to render, exactly where Mike needs to be glanceable and quiet. Studio for D3 Home: once you're actually dwelling with Mike and reading real conversation, Fraunces-on-glass holds prose in a way a control panel doesn't, and Home only ever shows one glass surface — the exact condition where its rendering cost is a non-issue. Signal I'd hold in reserve — not because it's weaker, but because its confidence is better spent on a single moment (first launch, a genuine win) than worn as the everyday interface.

That's my read. Tell me if you see it differently — these were built to be argued with, not defended.
